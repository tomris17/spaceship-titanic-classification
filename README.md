This repository contains an end-to-end machine learning solution for the **Kaggle Spaceship Titanic** competition. The objective is to predict whether a passenger was transported to an alternate dimension during the collision with a spacetime anomaly.

---

## 📊 Project Overview
* **Objective:** Build a robust binary classification model to forecast passenger transportation outcomes based on personal records, amenities usage, and cabin locations.
* **Key Steps:**
  * Exploratory Data Analysis (EDA) and missing value cleaning across passenger attributes.
  * Feature Engineering and data preprocessing (handling expenditures, cleaning cabins, and preparing numerical inputs).
  * Model Training and Evaluation using classification algorithms (such as Multinomial Naive Bayes).
  * Interactive web dashboard deployment via **Streamlit** for real-time model evaluation and confusion matrix analytics.

---
